# Spec Delta

## Purpose

为已登录的后台使用者提供可搜索、可分页的用户列表。通过一致的结果格式区分有数据和无匹配数据的情况，使使用者可以查找并定位需要维护的用户资料。

## ADDED Requirements

### Requirement: USR-001 用户列表查询

系统 SHALL 支持已登录使用者按关键词分页查询用户，关键词匹配用户名或姓名。查询 SHALL 排除已逻辑删除的用户，并返回当前页的用户列表及符合查询条件的记录总数。

#### Scenario: 关键词匹配

- **GIVEN** 测试数据包含用户名匹配、姓名匹配和已逻辑删除的匹配记录
- **WHEN** 已登录使用者使用同一关键词查询用户列表
- **THEN** 结果包含未删除的匹配记录，且总数排除已删除记录

#### Scenario: 请求第二页

- **GIVEN** 同一查询条件下有足够多的匹配记录，数据在两次请求间保持稳定
- **WHEN** 已登录使用者分别查询第 1 页和第 2 页
- **THEN** 返回对应页的记录，两页互不重复，且总数相同

#### Scenario: 无匹配数据

- **WHEN** 已登录使用者输入无匹配的关键词
- **THEN** 查询成功，返回空列表和总数 0
