# Proposal

## Why

用户列表已有前端、接口和查询实现，需要用可重复的场景复验现有行为，并为 `USR-001` 建立第一份业务能力规范。

## What Changes

- 验证已有用户列表的关键词搜索、分页、总数、空结果及删除标识过滤。
- 记录每个场景的运行证据与发现的差距。发现不符合预期的行为时，在台账关联后续修正变更。
- 分页参数的上限和非法参数处理由 `USR-002` 单独讨论。

## Capabilities

### New Capabilities

- `user-management` 用户资料维护与查询。本次建立用户列表的查询规范。

### Modified Capabilities

无。

## Impact

- 验收范围涉及用户页面、`GET /user/list`、查询参数映射和 MyBatis 查询。
- 验证依赖隔离环境及通过现有方式准备的测试账号和用户数据。实施前核对 `ENV-001`、`ENV-002` 的验收结果。
